  ### 1. 基础服务

  Docker Desktop 启动后运行：

  cd ~/apps/gogg
  make dev

  启动 PostgreSQL、Redis 和 Temporal。已经运行的话可以跳过。

  ### 2. 后端 API

  cd ~/apps/gogg
  GOGG_DATABASE_DSN='postgres://gogg:goggpass@localhost:55433/gogg_summoner_test?sslmode=disable' make run-api

  API 地址：http://localhost:8080

  注意 DSN 必须完整写在一行，?sslmode=disable 前面不能换行。

  ### 3. Worker

  cd ~/apps/gogg
  GOGG_DATABASE_DSN='postgres://gogg:goggpass@localhost:55433/gogg_summoner_test?sslmode=disable' make run-worker

  Worker 会执行 Riot API 查询、比赛数据抓取和本地图片缓存等后台任务。

  ### 4. 前端

  cd ~/apps/gogg
  make run-web

  浏览器打开：

  http://localhost:5173

  停止某个服务使用 Ctrl+C。这次前后端和 Worker 都有改动，因此之前已经运行的旧进程需要先停止再重
  新启动。不要使用 make dev-reset，它会重置本地开发数据。

 ### 5. TFT Worker

  make run-tft-worker

  然后另开终端执行一次手动抓取：

  go run ./apps/worker/cmd/crawlctl trigger \
    --schedule gogg-tft-crawl-global

  查看比赛抓取进度：

  go run ./apps/worker/cmd/crawlctl status \
    --schedule gogg-tft-crawl-global

  如果要开启定时自动抓取：

  go run ./apps/worker/cmd/crawlctl enable \
    --schedule gogg-tft-crawl-global
