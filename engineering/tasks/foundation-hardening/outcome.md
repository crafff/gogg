# 工程基础修复结果

本轮修复基础门禁漏验、暂存候选检查错位、失效知识阻断查询与任务入口陈旧。
产品功能、完整能力盘点、持久工作流和自动学习不属于本轮实现。

## 变更

- 基础检查校验必需角色和 Skill、模型与推理基线、权限配置、任务 JSON 与字段；
  任务只允许一份 active，completed 必须有结果记录。bootstrap 保留为历史任务。
- 提交检查从暂存 blob 建立隔离候选，保留原工作树和 index。缺少暂存文件、
  候选期间变化、私有路径或不支持的链接会阻断；不会执行迁移前的旧 Make 入口。
  清除 Git、Python 搜索路径及 Make 隐式配置环境，防止未暂存文件补足或绕过检查。
- 知识查询直接核实 facts 和来源后建立内存 FTS，删除磁盘 index 命令与 cache-dir。
  已过期 verified 和 inactive 来源变化产生警告，仍有效来源变化继续阻断。
  原有缓存不再读写，也没有删除；知识契约与 Skill 用法已同步。

## 候选与验证

受检文件、显式归档证据和工具版本见 [candidate.json](candidate.json)。清单排除
自身及本结果文件；它们的结构、链接和内容另外参加最后的基础检查及暂存扫描。
源内容或契约变更后，相关结果失效，不能仅凭此历史记录批准新版本。

验证环境为本机 Linux/WSL、Python 3.12.3、SQLite FTS5、Git 和 Gitleaks 8.30.1。

| 检查 | 结果与范围 |
|---|---|
| `make check` | 95 项通过：46 知识、15 基础、30 提交、4 安装器测试；基础与 6 条事实校验通过 |
| 实际知识查询 | 当前 Astra、中文 legacy 打野均命中；无需预建缓存 |
| 暂存候选集成 | 临时 Git 仓库中暂存当前新基础及显式归档引用，真实 precommit 内层 make check 与 Gitleaks 扫描通过 |
| 原 index 保护 | 原工作区尚未暂存新基础，直接 precommit 明确拒绝；原 index 保持原样 |
| 独立复核 | 发现并修复 MAKEFILES 绕过；补充 GNUMAKEFLAGS 空跑与 PYTHONPATH 未暂存来源反例，定向复核通过 |
| Skill 与差异检查 | 原生 quick_validate、基础文档检查和本轮 scoped diff 审查通过 |

提交单元场景中的扫描器为明确测试桩；集成验证使用真实 Gitleaks，未发现泄漏。
扫描只覆盖该临时暂存候选，不代表全量旧归档、Git 历史或外部数据已扫描。
本轮没有暂存原仓库文件、提交、推送、运行旧服务或改变备份与外部数据。
