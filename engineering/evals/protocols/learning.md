# 学习候选评测协议

状态：引导协议；受保护评分服务和模型评测尚未实现。

固定模型、权限、环境和输入，比较基础流程、当前发布和单机制候选；有随机性时
做配对重复。先验证完整验收、严重回归、知识误用、恢复和人工纠正，再衡量成本。

历史回放不得携带后来修复的 Git 对象、知识和隐藏答案。评分器用独立权限域，
候选不能修改它或读取答案；同仓库的隐藏文件夹不构成隔离。开发/验证/保留集
分别使用，保留集反复选择会泄漏信号，须记录访问并补新任务。

候选由真实失败或明确假设出发；记录适用范围、增量补丁、反例、评价器版本、
配对运行、接受决定和回退组合。一次成功不足以证明技能能泛化。

初期真实任务优先覆盖未提交恢复、过时知识、终态重试、生成漂移、浏览器流程、
性能竞争与统计泄漏。工具单元测试不是这些模型任务的完成证据。
