# ADR 0001：保存旧工作区，建立无兼容负担的新根目录

状态：用户授权；2026-09-04 请求，2026-09-05 UTC 实施。

决定：保留根 `.git/` 的历史和索引；工作树原件归档到用户指定拼写 `legecy/`。
旧功能、实验和变更作为参考，旧技术栈、构建、CI、路径及指导不再拥有新工程权威。
新的 AGENTS、原生配置、技能、工程知识与工具从独立根开始。

保存要求：含未提交、未跟踪、ignored 文件、Git 元数据和原始符号链接；完整 tar
及独立 Git bundle，经哈希、源一致性和恢复检查验证。外部数据库/资产/实验制品
仅保留链接，不把工作区备份误称为外部业务数据备份。

拒绝方案：直接删除旧内容会丢失尚未提交的工作；沿用旧根配置会保留不必要的
架构约束。仅靠 Git bundle 无法保存未提交/未跟踪及被忽略的工作。

后果：旧 make/dev 不再在新根运行；旧环境内的绝对路径和可执行环境不保证在
归档位置可运行。需要回溯时先恢复到独立目录，不能覆盖当前根或自动启动旧服务。
本轮不创建提交、不推送、不修改外部数据。具体证据见[迁移记录](../migrations/2026-09-05-clean-rebuild.md)。
