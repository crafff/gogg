# 产品目标

用户授权自由重建，不要求旧文件、旧路由或旧 API 的技术兼容。要求保全已有
用户能力，并持续建设超越 OP.GG、腾讯 101 等产品的体验和分析能力。

先以单机稳定、高吞吐、低延迟、低内存为产品部署目标，再测试多机。自动采集、
限流管理、断点恢复、历史版本数据集与可重现分析是长期能力。

当前 LoL/TFT 功能从归档代码建立能力基线；旧实现仅提供行为证据，不决定新栈。
区域、版本、队列、语言、匿名/登录、缺失数据、错误终态和重连均纳入保全。
基线缺项不能用局部任务全部通过来掩盖；删减或延期需要明确决定。

新增方向包括个性化英雄推荐、取胜因素分析、基于玩家战绩与风格的训练建议和
长期反馈。已有离线研究与上线能力分别标记。预测解释不等于因果干预；推荐的
收益需要与简单基线及前瞻性用户效果比较，不能以 LLM 自评替代。

竞品体验在同设备/网络/地区/用户任务下实测。没有内部证据时，不推断竞品架构、
内存或吞吐，也不预先承诺一个没有基线的性能数字。

详细评测要求见[产品验收设计](../design/product-contract.md)。
