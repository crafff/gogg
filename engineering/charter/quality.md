# 质量原则

优先级：用户目标和正确性 → 数据/安全/恢复 → 用户体验 → 性能与资源 → 实施速度。
模型预算质量优先，使用当前最强可用模型，当前配置基线为Astra；不能以调用数量替代质量证据。

验收必须匹配契约、候选、数据、环境和评价器版本。测试不存在或环境不可用时，
保留缺口，不把检查命令成功等同业务行为正确。构建、索引和维护不得污染性能测量。

新任务保持清晰的行为切片。研究、假设、实现观察、本地验证与真实用户结果分开。
同模型多 Agent 可能共同犯错，独立上下文只减少解释偏置，不替代行为验证。

维护成本也是质量：采用成熟机制之前验证适配语义；通用流程不无界自研；不为了
新技术名字引入未经证明的依赖、常驻服务或多重状态所有者。

研发经验、玩家个人数据、业务历史数据集分开存储、授权和保留。原生个人记忆
不自动获得工程事实权威；新经验不自行提升为强制规则。
