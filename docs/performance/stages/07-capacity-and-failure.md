# 阶段 7：容量测试与故障演练

## 目标

得到单实例安全容量、扩容信号、依赖故障行为和恢复时间。

## 容量步骤

按 `5 -> 20 -> 50 -> 100 VU` 逐级增加，每级观察 p95、错误率、CPU、连接池等待
和数据库利用率。只有前一级稳定后才能继续。

停止条件：

- 5xx 持续超过 1%。
- p95 持续超过 SLO 两倍。
- 数据库连接池持续饱和。
- 容器 OOM、严重 swap 或依赖健康恶化。

## 故障步骤

- 停止本地 Redis。
- 在隔离环境降低 PostgreSQL 连接上限或增加延迟。
- 负载期间重启 API。
- 模拟慢客户端和请求取消。
- 验证 readiness、告警、降级和恢复。

## 验收标准

- 得到单实例安全 RPS、资源配置和容量拐点。
- 明确扩容触发点、降级行为和恢复时间。
- 所有演练都有停止和恢复步骤，不直接对生产执行破坏性操作。
